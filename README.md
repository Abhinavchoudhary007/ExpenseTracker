💰 Expense Tracker Web App
A user-friendly Expense Tracker web application built with Django, enabling users to efficiently add, view, edit, and delete their daily expenses. The app also provides interactive summaries and charts for better expense analysis over different time periods.
🔑 Key Features
📌 Navigation Bar with smooth scroll to key sections:
Add Expense
Expenses List
Total Expenses by Days
Table View
Charts
Contact Me
📆 Time-based Summaries

Total expenses for the last 7, 30, and 365 days.
📊 Data Visualization
Interactive charts using Chart.js.
Responsive tables to display all expense entries.
💡 Django-Powered Backend

Dynamic rendering of expense data using Django templates.
Secure form handling with CSRF protection.
🎨 Responsive UI

Built with Tailwind CSS for modern styling across all devices.
📇 Contact Footer

It includes your author info along with links to LinkedIn and GitHub.
🛠️ Technologies Used
Backend: Django (Python)
Frontend: HTML, Tailwind CSS, JavaScript
Charts: Chart.js
Database: SQLite (default for Django)
